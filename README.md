
# PRISMA — Price Comparator

PRISMA es un proyecto de portafolio enfocado en la comparación
de precios de productos tecnológicos.

## Objetivo

Desarrollar una aplicación web que permita explorar productos,
comparar precios entre diferentes tiendas y descubrir mejores
oportunidades de compra.

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Funcionalidades previstas

- Catálogo de productos tecnológicos.
- Buscador de productos.
- Filtros por categoría y precio.
- Comparador de precios.
- Lista de favoritos.
- Historial de precios.
- Diseño responsive.
